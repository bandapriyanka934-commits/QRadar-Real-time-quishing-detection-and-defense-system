Scoring Policy Reference

• 0 – 29 (SAFE / ALLOW): Clean heuristics, low ML probability, and clean reputation.
• 30 – 69 (SUSPICIOUS / WARN): Anomalous structure or URL shorteners requiring user confirmation.
• 70 – 100 (MALICIOUS / BLOCK): Dangerous schemes (javascript:), brand typosquatting, rogue IP hosts, high ML probability, or threat feed hits.
